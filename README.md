🎮 Hangman Game

📌 Project Description

Hangman is a simple word-guessing game developed using Python. The player must guess a hidden word one letter at a time. The player wins by guessing all the letters correctly before running out of attempts.

🎯 Objective

To develop a fun and interactive word-guessing game using basic Python programming concepts.

🛠️ Technologies Used

Python 3
VS Code
✨ Features

Random word selection
Letter-by-letter guessing
Limited incorrect attempts
Displays correctly guessed letters
Shows win or lose messages
▶️ How to Run the Project

Install Python 3 on your computer.
Download or clone this repository.
Open the project folder in VS Code.
Open the terminal.
Run the following command:
python hangman.py

If that command does not work, try:

python3 hangman.py

🎮 How to Play

Run the Python program.
View the hidden word represented by blanks.
Enter one letter at a time.
Guess the word before your attempts run out.
You win if you guess the complete word correctly!
